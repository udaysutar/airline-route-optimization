# ✈️ Airline Route Optimization System

## 📌 Project Overview
The Airline Route Optimization System is a machine learning-based application designed to help airlines choose the most efficient flight routes. It considers multiple real-world factors such as distance, weather conditions, aircraft type, and operational cost to generate optimized routes.

---

## 🚀 Features
- 🌍 Interactive route selection
- 📏 Distance calculation using Haversine Formula
- 🌦 Weather impact analysis
- ✈️ Aircraft type-based optimization
- 💰 Revenue and cost estimation
- 📊 Data-driven decision making

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS
- **Backend:** Python (Flask)
- **Libraries:** Pandas, NumPy, Scikit-learn

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository
git clone https://github.com/your-username/airline-route-optimization.git
cd airline-route-optimization

### 2️⃣ Create virtual environment
python -m venv venv
venv\Scripts\activate (Windows)


### 3️⃣ Install dependencies
pip install -r requirements.txt


### 4️⃣ Run the application
python app/app.py


### 5️⃣ Open in browser
http://127.0.0.1:5000/
